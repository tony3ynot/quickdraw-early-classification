# mamba2_20cls: test 평가 결과

## 조건
- 데이터: 공식 Sketch-RNN QuickDraw 분할, 20개 클래스, test 50,000개 중 50,000개 평가
- 모델: 2-layer Mamba, d_model 256 (파라미터 883,220개), 체크포인트 epoch 28

- 평가: batch size 1, NVIDIA L4, fp32, 관찰 시점 10개 (10%~100%)
- 학습: train 1,400,000개, 30 epoch, 2.90시간 (NVIDIA L4), best epoch 28

## 측정 가정
- 관찰 비율 f 시점에는 앞에서부터 ceil(점 개수 × f)개(최소 1개)의 점을 본다.
- 상태 유지: 상태를 이어 가며 새로 들어온 점만 하나씩 처리한다 (mamba-ssm의 step). 시점마다 재추론: 그때까지의 prefix 전체를 처음부터 다시 추론한다. 두 방식 모두 실제로 실행해 측정했다.
- FLOPs는 곱셈-덧셈 1회를 1로 세고(fvcore 기준), 활성화·정규화는 세지 않는다. 점 하나당 924,416 FLOPs에 모델이 계산한 점 개수를 곱한다.
- 지연 시간은 모델 계산 + softmax + 결과를 CPU로 가져오는 시간이며 전처리는 제외했다.
- 모델은 causal이어서 각 시점의 예측에 그 뒤의 점을 쓰지 않는다. 단, 원본 데이터의 좌표는 완성된 스케치 기준으로 0~255로 맞춰져 있다 (README의 '알려진 한계').
